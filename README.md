# Describe Your Ex in One Word

A program that writes exactly one word to `/output/entry.txt` — a one-word verdict describing my ex. Built for the make.fun competition **"Describe Your Ex in One Word"** (`u-puan-describe-your-ex-in-one-word-9fc6ebe7`).

## The word

> audition

The word works because it reframes the whole relationship as a casting call: my ex was never the lead, just someone trying out for the part who did not get it. It is a real word, instantly readable as a verdict on a former partner, and it lands without any explanation. The twist is the demotion — not a villain, not a tragedy, just an unsuccessful tryout. It is surprising (nobody's first insult for an ex) yet painfully relatable: everyone has been the audition, or has sat through one. No insult, no punctuation tricks, just the quiet comedy of being recast.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
